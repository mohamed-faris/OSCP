The 5-Phase Plan

P0 Foundations Weeks 1-3 ▶
Solid Linux, networking, and scripting base. You can't hack what you can't navigate.
What to learn
  • Linux CLI fluency — filesystem, permissions, processes, cron, services
  • Networking deep dive — TCP/IP, DNS, SMB, SNMP, HTTP, FTP
  • Bash scripting — loops, conditionals, parsing tool output
  • Python basics — requests, sockets, modifying exploit scripts
  • Kali Linux setup — VM configuration, tool familiarity
Practice rooms
THM: Pre Security Path THM: Linux Fundamentals 1-3 THM: Bash Scripting THM: Intro to Networking THM: Network Services 1 & 2
Milestone
SSH into a box, navigate the filesystem, write a Bash loop, explain a 3-way TCP handshake.
P1 Core Pentesting & Enumeration Weeks 4-8 ▶
Learn the attack lifecycle. Build your repeatable methodology. Enumeration = 40% of exam time.
Enumeration
  • Port scanning — Nmap SYN scans, version detection, NSE scripts
  • Web enumeration — Gobuster/Feroxbuster, Nikto
  • SMB — enum4linux, smbclient, NetExec
  • SNMP — snmpwalk, onesixtyone
Web attacks (build on your strength)
  • SQL injection (manual only — sqlmap is banned on exam)
  • Local/Remote File Inclusion (LFI/RFI)
  • Command injection, file upload vulns, directory traversal
Shells & exploits
  • Reverse/bind/web shells + stabilization
  • SearchSploit/ExploitDB — find and adapt public exploits
  • Msfvenom payload generation
Practice
THM: Jr Penetration Tester (89 rooms) THM: Nmap THM: OWASP Top 10 THM: SQL Injection THM: What the Shell

Also: PortSwigger Web Security Academy (free) for SQLi and file inclusion labs

YOUR METHODOLOGY (start building this now) 1. Nmap full port scan (-p-) 2. Service version scan on open ports (-sV -sC) 3. Per service: HTTP → gobuster; SMB → enum4linux; etc. 4. searchsploit <service version> 5. Check default creds, sensitive files, info disclosure 6. Identify attack vector → exploit → shell
Milestone
Enumerate a target, find a web vuln, get a shell, and explain each step without notes.
P2 Privilege Escalation Weeks 9-13 ▶
You got a shell. Now become root/SYSTEM. This is where most beginners stall.
Linux privesc
  • SUID/SGID binaries (GTFOBins)
  • Cron job abuse + writable PATH hijacking
  • sudo -l misconfigurations
  • Capabilities, NFS no_root_squash
  • Kernel exploits (last resort)
  • Sensitive file discovery — config passwords, SSH keys, .bash_history
Windows privesc
  • Service misconfigs — unquoted paths, weak permissions
  • Token impersonation — SeImpersonatePrivilege → Potato attacks
  • Always Install Elevated, scheduled tasks
  • Registry autoruns, DLL hijacking
  • Credential harvesting — SAM, LSASS, cached creds

Given a low-priv shell on Linux or Windows, find and exploit a privesc path in 30-60 minutes.
P3 Active Directory Weeks 14-18 ▶
Make-or-break section. 40% of the exam. You cannot pass by skipping AD.
The AD attack chain
Initial foothold (web app / phishing on domain machine) ↓ Enumerate domain → BloodHound, PowerView, ldapsearch ↓ Find attack paths → Kerberoastable SPNs, AS-REP users ↓ Credential attacks → Kerberoasting, AS-REP roasting, spraying ↓ Crack hashes offline → hashcat / john ↓ Lateral movement → Pass-the-Hash, psexec, wmiexec, evil-winrm ↓ Domain escalation → DCSync, Golden/Silver tickets ↓ Compromise Domain Controller
Techniques to master
  • Kerberoasting — GetUserSPNs.py (any authenticated user can do it)
  • AS-REP Roasting — GetNPUsers.py (no password needed to start)
  • Pass-the-Hash — psexec.py, wmiexec.py, evil-winrm
  • DCSync — secretsdump.py (pull all domain hashes)
  • Password spraying — NetExec against SMB/LDAP
  • BloodHound + SharpHound — visualize attack paths
Key tools — Impacket suite is essential

Compromise a 3-machine AD set (DC + 2 workstations) end-to-end in under 4 hours.
P4 Tunneling, Grinding & Mock Exams Weeks 19-24 ▶
Tie everything together. Practice under exam conditions. Target 40-70 machines total.
Tunneling & pivoting

Lessons From People Who Failed (Then Passed)

Rabbit holes kill exams
"I wasted 7.5 hours trying to pivot laterally when I should have moved on after 1 hour."

Rule: stuck for 60-90 minutes with no progress? Move to another machine. Come back later.

Unbalanced practice
"~80% of the boxes I'd solved were Linux. I was completely weak on Windows and AD."

Force yourself onto Windows boxes. The exam has both OS types plus the AD set.

Weak enumeration
"I missed obvious low-hanging fruit because I rushed through enumeration."

Enumeration IS the exam. Build a checklist and follow it religiously on every machine.

The report is half the exam
"I hacked the machines but lost points because my documentation was incomplete."

Screenshot everything. Document commands. Write the report as you hack, not after.

No mock exam
"Mock exams helped with mental conditioning and stress more than anything."

If your first 24-hour session is the real exam, fatigue and time pressure will hit harder.

Burnout
"I didn't realize how mentally burnt out I was."

Marathon, not sprint. 2-3 hours weekdays, 4-6 weekends. Take rest days.

Exam Day Strategy

H 0-2 Read all machines. Start with the easiest-looking standalone. Build momentum.
H 2-6 Move to the AD set while fresh. Target full compromise. This is your highest-value block.
H 6-10 Tackle remaining standalones. Time-box 2-3 hours each max.
H 10-12 Real break. Sleep if needed. Eat a proper meal. Step away from the screen.
H 12-18 Return to anything unfinished with fresh eyes. Run background scans while working.
H 18-24 Polish documentation. Screenshot review. Verify all flags are captured.

Buy PEN-200 around Week 14-16. You'll get the most from the 90-day lab access with foundations already in place.
